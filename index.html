Lab Note: This application demonstrates reading XML data using both fetch() / DOMParser() and local file loading via FileReader(). When using fetch(), run through a local web server (e.g. VS Code Live Server or python -m http.server) to comply with browser CORS policies. If opened directly via file:/// protocol, use the "Choose XML File" button to load employees.xml directly without browser security blocks.
